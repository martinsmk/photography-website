# Car Photography Portfolio

A simple and elegant photography website showcasing my favourite car photographs.

Moringa School Student

## Description
This is my Independent Project for Week 2 at Moringa School.  
The website displays a personal collection of car photographs that I love,  
along with a short biography, a design section, and a contact form.

The site is built using only HTML and CSS  and focuses on  
clean layout, visual appeal, and proper use of the concepts learned in class.
